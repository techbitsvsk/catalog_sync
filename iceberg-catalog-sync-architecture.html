6. Sync Consistency Guarantee — Atomic commit via version-hint.text

sequenceDiagram participant S as Source (AWS S3) participant CS as CatalogSync participant T as Target (Azure ADLS) Note over S,T: Target may have previous version (v2) or nothing CS->>S: find_latest_metadata() S-->>CS: v3.metadata.json CS->>S: list data files CS->>T: list data files (diff) Note over CS: Only new files need copying CS->>S: read new data files CS->>T: write new data files Note over T: Data files in place, but v2 metadata
still active — target reads OLD state CS->>S: read manifest (Avro) CS->>CS: rewrite file_path URIs CS->>T: write rewritten manifest CS->>S: read manifest-list (Avro) CS->>CS: rewrite manifest_path URIs CS->>T: write rewritten manifest-list CS->>S: read metadata.json CS->>CS: rewrite location + snapshot paths CS->>T: write rewritten metadata.json CS->>T: write version-hint.text = "3" Note over T: ATOMIC SWITCH — target now reads v3
